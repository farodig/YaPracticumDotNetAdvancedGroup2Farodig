# Сервис пользователей
## PersonService API
|Метод |Адрес            |Запрос                                         |Ответ                              |Описание                           |Доступ (Роль)|
|------|-----------------|-----------------------------------------------|-----------------------------------|-----------------------------------|-------------|
|POST  |/auth/register   |[RegisterPersonRequest](#registerpersonrequest)|                                   |Регистрирует пользователя,         |Аноним       |
|POST  |/auth/login      |[LoginPersonRequest](#loginpersonrequest)      |string (токен авторизации)         |Авторизует пользователя,           |Аноним       |

## Схемы запросов/ответов
### RegisterPersonRequest
|Поле     |Тип данных   |Описание           |Пример             |
|---------|-------------|-------------------|-------------------|
|Login    |string       |Логин пользователя |"User"             |
|Password |string       |Пароль пользователя|"Admin"            |
|Role     |enum         |Роль пользователя  |0 - User, 1 - Admin|

### PersonRole - Роль пользователя
User - обычный пользователь
Admin - администратор

### LoginPersonRequest
|Поле     |Тип данных   |Описание           |Пример             |
|---------|-------------|-------------------|-------------------|
|Login    |string       |Логин пользователя |"User"             |
|Password |string       |Пароль пользователя|"Admin"            |

## Примеры запросов
### Пример запроса с регистрацией пользователя
#### Запрос
POST /auth/register
{
  "login": "Admin",
  "password": "Admin"
  "Role": "1"
}

#### Ответ
Status code 204

### Пример запроса с авторизацией пользователя
#### Запрос
POST /auth/login
{
  "login": "user324",
  "password": "mysupersecretpassword123"
}

#### Ответ
Status code 200
<token> - строка токен для авторизации
